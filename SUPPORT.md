# Support

Community Edition support is best effort — no response-time or resolution SLA.

Use the issue tracker of the canonical public repository,
<https://forgejo.xtrape.com/xtrape-project/linux-ops-widget-nodejs/issues>
(where available), or the project role address published at
<https://xtrape.com/governance/>, for reproducible bugs and feature requests;
use the private security channel for suspected vulnerabilities. Never include
passwords, tokens, private keys, or unredacted personal data.

Canonical policy:
<https://xtrape.com/governance/>
